One emoji, one smile: this program writes a single emoji — 🤗, the hugging face — to `/output/entry.txt`. A big smile with open arms is the warmest thing a stranger can receive at a glance: friendly without a word, universal across ages and backgrounds, clearly picked rather than the default smiley, and a virtual hug reads as kind, never intimate or flirtatious, from someone unknown.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (on Node 22.6–22.17, run `node --experimental-strip-types main.ts`). The output directory comes from `MAKEFUN_OUTPUT_DIR` and defaults to `/output`; the program creates it if needed and writes exactly one emoji, nothing else, to `entry.txt`.
